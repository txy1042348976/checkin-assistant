# 签到助手 · 浏览器连接

这个可选扩展让你直接在自己的 Chrome 或 Edge 浏览器中登录 AnyRouter、AgentRouter 或已配置的兼容站点，再主动将本次站点登录状态交给自己的签到助手保存。登录页面来自原站，扩展不提供远程浏览器，也不执行登录、验证码、授权确认或签到。

## 安装

1. 解压签到助手源码包，找到 `browser-extension/` 文件夹。文件夹内须直接包含 `manifest.json`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展」，选择该文件夹。
4. 在浏览器工具栏固定「签到助手 · 浏览器连接」，便于在原站登录后打开。

此版本适用于支持 Manifest V3 和 `chrome.storage.session` 的 Chromium 浏览器；不支持无扩展的手机浏览器、Safari 或 Firefox。无需上传到商店或安装服务器组件。

## 使用

1. 在你自己的签到助手中添加或重新授权账号，选择站点和登录方式，开始授权。
2. 从主页面授权进度中复制「浏览器连接码」。连接码形如 JSON，包含助手地址、本次连接编号和一次性短期票据。
3. 点击工具栏扩展图标，粘贴连接码并点击「连接签到助手」。访问权限提示会显示你自己的助手域名，确认地址正确后允许。
4. 保持原站登录页面为浏览器当前标签页，使用要关联的账号完成登录。返回原站的账号控制台后再次打开扩展。
5. 点击「导入登录状态」，允许当前目标站点权限。扩展先从原站身份接口读取并核对当前身份，再读取此站点的 Session 或登录 Token。
6. 后台会再次验证目标站点身份和余额，然后加密保存。扩展完成后清除当前浏览器会话中的连接票据和本次站点访问权限。返回签到助手查看结果。

每个站点分别生成连接码、分别导入，连接码不会放进原站网址。多个站点在同一浏览器完成登录时，也不会把一个站点的 Cookie 直接复制给另一个站点。重新授权已有账号时，后台会核对原账号身份，避免覆盖成另一个账号。

如果浏览器 Cookie 读取或站点验证不兼容，可直接在签到助手中使用手动 Session 导入。

## AgentRouter 的可选后台登录状态

AgentRouter 的奖励通常由重新 OAuth 登录产生，仅目标站 Session 可供余额查询，不能据此确认已领取奖励。为保留现有后台登录能力，在连接方式为 GitHub 或 LinuxDO 的 AgentRouter 连接中，会提供默认关闭的「同时保存登录状态」选项。

勾选后会额外申请所选身份提供方的域名权限，并仅读取当前浏览器 Cookie 空间中该身份提供方的 Cookie：GitHub 为 `github.com` 与子域，LinuxDO 为 `linux.do` 与子域（包括 `connect.linux.do`）。它们将交给你自己的服务器加密保存，以便后续重新登录。请只在原站与身份提供方使用同一个预期账号时启用。登录 Cookie 具有持续访问能力，比只导入目标站 Session 的权限范围更广；不需要后台 OAuth 登录时保持关闭。

后台登录仍受 Cookie 有效期、站点验证码、账号授权及服务器网络影响；扩展不会将余额同步标记为签到成功，也不会保存 GitHub/LinuxDO 密码。

## 权限与数据

- `activeTab`：用户点击扩展后，识别当前标签页，目标原站不匹配时拒绝导入。
- `scripting`：只在当前目标站的顶层页面执行一个本地、只读的身份查询。不会注入到其他标签页，不注册常驻页面脚本。
- `cookies`：读取目标站 HttpOnly Session 与配置中的防护 Cookie；只有明确勾选额外选项后才读取所选身份提供方的登录状态。
- `storage`：连接票据保存在 `chrome.storage.session`，仅扩展可信页面可读，最长 20 分钟；不保存导入的 Cookie、Token 或身份提供方密码。
- 可选网站访问权限：安装时不申请全站访问，点击连接/导入时只为本次助手、目标站点及明确勾选的身份提供方申请访问。Chrome 的域名权限涵盖该域名的端口；扩展的实际请求仍严格使用连接码中完整的协议、主机和端口。

凭据仅通过一次性票据发送到连接码指向的助手，HTTP 请求显式使用 `credentials: 'omit'`，不附带助手管理员 Cookie。远程助手须为 HTTPS，本机 `localhost`、`127.0.0.1` 或 `[::1]` 可用 HTTP。扩展不发送遥测、不访问第三方分析服务、不开启调试端口、不读取浏览历史、不复制全部浏览器 Cookie，也不会把读取到的凭据发送给原站以外的第三方服务器。

扩展不自动安装或授予权限；安装和浏览器权限选择由本人完成。扩展关闭或浏览器重启后，连接信息可能消失，回助手复制新连接码即可。

```bash
node --test browser-extension/tests/*.test.mjs
```

测试使用假的 Cookie、Chrome API 和 HTTP 响应，覆盖精确目标绑定、票据处理、Cookie 空间和路径、先后身份一致性、数据范围、凭据不附带管理员 Cookie 与错误信息保密，不读取真实账号。
